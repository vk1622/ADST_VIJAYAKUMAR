SmartGroceries

Project Report

1. Abstract

SmartGroceries is a smart kitchen management and food waste reduction system designed to help users track vegetables, monitor freshness, and receive recipe suggestions based on what they already have at home. The system combines a web-based frontend, a backend API, and a machine learning model to estimate shelf life and improve household food management. The main goal is to reduce food waste by encouraging users to consume items before they spoil and by suggesting practical meals from available ingredients.

The project addresses a common daily problem faced by households: fresh produce is often forgotten, stored for too long, and eventually wasted. SmartGroceries provides a simple inventory system where users can add vegetables, record storage duration, and view food freshness status. It also recommends recipes based on ingredient availability and helps users plan meals using the “2–2–2” concept: choose two vegetables, two pantry ingredients, and get two meal ideas.

By integrating data management, recipe recommendation, and predictive shelf-life estimation, the system offers a user-friendly solution for smarter grocery planning and healthier consumption habits. It is designed to be accessible, practical, and beneficial for both individuals and families seeking to reduce food waste.

2. Introduction

Food waste is a growing global problem, and a significant part of it occurs in households where vegetables and groceries are not tracked properly. Many people buy vegetables without keeping track of how long they have been stored. As a result, fruits and vegetables often become spoiled before they are used. This leads to unnecessary waste, increased expense, and poor food management.

SmartGroceries is developed to solve this issue by creating a digital kitchen assistant that helps users record and monitor the status of food items. The application allows users to add vegetables to their kitchen inventory, view freshness levels, and get recipe recommendations based on the items they already have. The system also estimates shelf life using a machine learning model, helping users know which vegetables should be used first.

The project is a combination of a frontend interface, backend API, and prediction model. The frontend is built with React, while the backend is built with Flask. The system makes food management easier and encourages users to cook and use ingredients before they spoil. This makes SmartGroceries useful not only for personal convenience but also for environmental sustainability.

3. Problem Statement

Households often face challenges in managing fresh groceries efficiently. Some of the key issues include:

  • Vegetables are purchased in bulk and forgotten in storage.
  • Users are unsure which items should be consumed first.
  • A large amount of food is wasted due to poor tracking and planning.
  • There is no simple tool that combines ingredient tracking with recipe suggestions.
  • Grocery planning is often done without considering what is already available at home.

These problems lead to food spoilage, financial loss, and poor usage of available resources. There is a strong need for a smart system that tracks food inventory, estimates remaining shelf life, and recommends meals based on available ingredients. SmartGroceries addresses this need by combining food tracking with recommendation and prediction features.

4. Existing System

The existing system for food management in many households is mostly manual. Users often rely on memory, handwritten notes, or visual inspection to know what is in the kitchen and whether food is still fresh. This approach has several drawbacks:

  • It is difficult to track inventory accurately.
  • Vegetables are often forgotten until they are spoiled.
  • The freshness of food is judged based on guesswork.
  • There is no automated recommendation for meals or leftover usage.
  • Manual planning does not consider food expiry timing or shelf life.

In some cases, people may use basic mobile notes or spreadsheets, but these are not intelligent or interactive. They do not estimate remaining shelf life or suggest recipes automatically. This creates inefficiency and results in unnecessary food waste.

5. Proposed System

The proposed system, SmartGroceries, aims to replace manual food tracking with an intelligent digital solution. It provides a user-friendly web application where users can:

  • Add vegetables to their kitchen inventory.
  • Record quantity, storage type, and number of days stored.
  • View freshness status such as Fresh, Use Soon, or Use Today.
  • Receive recipe suggestions based on available ingredients.
  • Plan meals using a simple 2–2–2 method.
  • Save favorite or planned meals.
  • Use a machine learning model to estimate shelf life.

The system uses a React-based frontend for a modern and interactive user experience and a Flask backend to handle prediction requests. The backend loads a trained machine learning model and predicts shelf life based on ingredient and environmental attributes such as storage method, temperature, humidity, and days since purchase.

The proposed system reduces food waste by helping people consume perishable items before they expire and by enabling better meal planning.

6. About the Dataset

The dataset used in the project includes vegetable information and recipe information necessary for kitchen planning and recommendation. The dataset is structured in JSON format and contains:

  • Vegetable names
  • Food type and category
  • Typical shelf life
  • Storage recommendations
  • Recipe names and ingredients
  • Cooking time and category
  • Pantry items required for each recipe
  • Steps to prepare the food

The vegetable dataset contains items such as Tomato, Spinach, Potato, Carrot, Broccoli, Capsicum, Cucumber, Onion, Brinjal, and Zucchini. Each item includes general shelf-life information and storage tips. This helps the system provide realistic freshness guidance and recommendation logic.

The recipe dataset contains a variety of meal suggestions such as stir-fry, soup, curry, salad, and tray-baked dishes. Each recipe includes ingredients, pantry items, cooking time, and preparation steps. The system matches these recipes to the vegetables in the user’s inventory and ranks them based on how many ingredients are already available.

The machine learning model uses structured food-related data such as food name, category, storage method, temperature, humidity, quantity, and purchase date details to estimate shelf life in days. This makes the prediction process more effective and meaningful for food management.

7. Technologies Used

The SmartGroceries project uses a combination of modern web, backend, and machine learning technologies:

  • Python: Used for backend logic and machine learning model development.
  • Flask: Lightweight web framework used to build the API server.
  • React: Frontend JavaScript library used to build the interactive user interface.
  • Vite: Fast development tooling for the frontend.
  • JavaScript / JSX: Used for interface logic and UI rendering.
  • Pandas: Used for dataset loading and data processing.
  • Scikit-learn: Used for training and evaluating the shelf-life prediction model.
  • Pickle: Used to save and load the trained model.
  • JSON Data Files: Used for vegetable catalog and recipe dataset storage.
  • Local Storage: Used in the browser to save inventory, favorites, and meal plans.

These technologies together enable a smooth user experience and efficient intelligent data processing.

8. Data Flow Diagram

The system follows a simple and practical data flow. The user adds vegetables to the inventory in the frontend, the frontend stores and validates the item, the backend processes requests, the machine learning model predicts shelf life, and the result is returned to the user. The system then suggests recipes and helps the user decide what to cook first.

9. Conclusion

SmartGroceries is a useful and practical solution for reducing household food waste and improving food planning. The system helps users manage vegetables more efficiently, prioritize items that need to be used soon, and make better meal decisions based on what they already have at home. By combining inventory tracking, recipe recommendation, and shelf-life prediction, the project provides a modern and intelligent method for kitchen management.

The project demonstrates how technology can be used to support everyday needs in a simple and effective way. It is especially valuable for people who want to reduce waste, save money, and make smarter grocery decisions. With further improvements such as image recognition, mobile app support, and more advanced predictive models, SmartGroceries can become an even more powerful smart home food assistant.
